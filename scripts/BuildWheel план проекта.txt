Задача - создать мод на последнюю версию Mindustry, а именно колесо выбора блоков для строительства. Оригинальная система крайне неудобная. Имею опыт одного мода - простенького скрипта java script в одном файле вида main.js (как создавать ещё файлы скриптов, вызывать друг друга ими и передавать информацию пока понятия не имею).
Поэтапный пример работы мода:
 1)Открытие полупрозрачного колеса происходит нажатием клавиш [shift] + [цифра].
	1.2)Колесо под номером [цифры] открывается поверх всего на экране в месте расположения мышки. 
 2)В колесе выбор из 8 вариантов (как по сторонам света) (на каждом варианте может быть отображена иконка блока, по умолчанию слоты пусты).
	2.1)при нажатии ЛКМ не на один из секторов колесо закрывается;
	2.2)при нажатии ПКМ колесо закрывается
	2.3)При нажатии ЛКМ на сектор предмет там указанный в качестве иконки выбирается в качестве блока для строительства;
 3)При открытом колесе выбора комбинация [tab] + ЛКМ по указанном сектору открывает меню c:
	3.1)листом всех блоков строительства на выбор, пролистывается колёсиком вверх-вниз
	3.2)с стройкой для фильтрации листа по названию 
	3.3)ползунок размера данной иконки [40 - 200%]
	3.4)кнопка закрытия настроек
 
 4)Дополнительные настройки в меню:
	4.1)Курсор мышки не может покинуть диапозон колеса выбора [да/нет]
	4.2)Размер колеса выбора [10 - 200%]
	4.3)Задать прозрачность колеса [10 - 100%]
	4.4)Задать клавишы "Открытие колеса" (по умолчанию [shift]), "Настройка сектора колеса" (по умолчанию [tab])
	
 5)Локализация
